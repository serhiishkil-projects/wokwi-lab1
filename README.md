# Лабораторна робота № 1 — Blink у Wokwi

**Студент:** Шкіль Сергій Валерійович  
**Група:** ТРРЗВС-26-1  
**Платформа:** Arduino UNO

## Опис проєкту

У симуляторі Wokwi створено схему з Arduino UNO, світлодіодом і резистором 220 Ом.
Світлодіод підключено до цифрового піна D8. Програма періодично вмикає його
на 1 секунду та вимикає на 1 секунду.

## Схема підключення

D8 → резистор 220 Ом → анод LED (+); катод LED (−) → GND.
